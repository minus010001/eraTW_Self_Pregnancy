# 引擎层动画指令 — 工作手册

> 目标：在引擎层实现文本动画（打字机/fade）和图片特效（fade/百叶窗/闪烁/震动），消除 ERB 层 FOR+TWAIT+CLEARLINE 循环的性能开销。
> 知识库参考：[print-rendering.md](file:///d:/emuera/shared-trae/knowledge/erabasic/print-rendering.md)、[layer-rendering-applications.md](file:///d:/emuera/shared-trae/knowledge/erabasic/layer-rendering-applications.md)

## 1. 问题分析

### 当前 ERB 层动画的性能瓶颈

| 效果 | ERB 实现 | 每帧开销 | 瓶颈 |
|------|---------|---------|------|
| KEYTYPING | FOR+SUBSTRING+TWAIT+CLEARLINE | 字符串截取+行销毁+HTML解析+布局 | 20字=20次完整生命周期 |
| FADE/FADEIN/FADEOUT | FOR+SETCOLOR+PRINTSL+TWAIT+CLEARLINE | 30行×8帧=240次文本渲染 | 颜色渐变需重建整行 |
| ROLLTEXT | FOR+SUBSTRING+CLEARLINE+TWAIT | 字符串截取+行销毁+重建 | 跑马灯每帧全量重建 |
| 呼吸灯 | GETMILLISECOND+CALC_OSCILLATION_VALUE | 单次调用，无循环 | 无瓶颈（已高效） |
| FLASH | REPEAT 150 PRINTL + SETBGCOLOR + REDRAW | 150行空行+全屏重绘 | 低效但频率低 |
| QUAKE | FOR+PRINTL+TWAIT+CLEARLINE | 随机空行+全屏重绘 | 低效但频率低 |
| BGCOLOR_TRANSITION | FOR+SETBGCOLOR+AWAIT | 背景色渐变 | AWAIT 阻塞 |
| pops-tw VN 逐字打印 | FOR+SUBSTRINGU+INPUTMOUSEKEY+CLEARLINE+CBGCLEAR | 每帧清空CBG+重绘 | 极低效（全量CBG重绘） |
| pops-tw 标题画面 | CBGCLEAR+GCREATEFROMFILE+CBGSETG 每帧 | 全量G系操作 | 极低效 |
| 标题百叶窗 | 35×HTML_PRINT img（静态） | 无动画 | 需 SETIMAGELAYER+opacity 渐变 |

### 核心洞察

**ERB 层动画的根本问题**：每次更新都需要 CLEARLINE（销毁旧行）+ 重建新行。但动画过程中，行的**结构不变**，只有**渲染参数**在变化（可见字符数、颜色、位置）。

**引擎层优化**：保持行数据不变，只在渲染时修改参数。这和 SpriteAnime 的帧切换是同一思路——数据不变，只改变渲染范围。

## 2. 引擎渲染管线关键节点

### 2.1 文本行生命周期

```
ERB: PRINT "你好世界"
  ↓
PrintStringBuffer: 解析 HTML → ConsoleButtonString[]
  ↓
EmueraConsole.NewLine() → PrintFlush(true) → addDisplayLine()
  ↓
ConsoleDisplayLine: buttons[] 的容器
  ↓
OnPaint → DrawTo → 遍历 buttons → 遍历 nodes → 渲染
```

### 2.2 关键类与接口

| 类 | 职责 | 动画相关能力 |

```csharp
// ConsoleStyledString.cs:295
public ConsoleStyledString DivideAt(int index)

    if (index <= 0 || index > Text.Length || Error)
        return null;
    string str = Text[index..];
    Text = Text[..index];  // 修改自身！
    BuildFallbacks();       // 重建字体回退链
```

## 3. 设计方案

### 3.1 架构：IAnimatedDisplayLine 接口

```csharp
/// <summary>
/// 动画行接口。ConsoleDisplayLine 实现此接口（默认 IsAnimationComplete=true）。
/// 动画行覆盖相关方法，在渲染时修改参数而非重建行。
/// </summary>
interface IAnimatedDisplayLine
{
    /// <summary>动画是否完成</summary>
    bool IsAnimationComplete { get; }
    
    /// <summary>每帧更新动画状态</summary>
    /// <param name="elapsedMs">自动画开始以来的毫秒数</param>
    void UpdateAnimation(long elapsedMs);
    
    /// <summary>强制完成动画（跳过/快进）</summary>
    void ForceComplete();
    
    /// <summary>动画开始时间戳</summary>
    long AnimationStartTimeMs { get; }
}
```

### 3.2 TYPING_PRINT 指令设计

#### ERB 语法

```erb
; 异步模式：ERB 立即继续，动画在后台播放
TYPING_PRINT "你好世界", 50

; 同步模式：等动画完成才继续（等效 KEYTYPING）
TYPING_PRINTW "你好世界", 50

; 带换行
TYPING_PRINTL "你好世界", 50

; 前后半句切换（KEYTYPING 的 "/" 语义）
TYPING_PRINT "あくま/悪魔", 50
```

#### 参数

| 参数 | 类型 | 默认值 | 语义 |
|------|------|--------|------|
| text | string | 必需 | 文本内容（支持 HTML） |
| delay | int | 50 | 每字延迟（ms） |
| chunkSize | int | 1 | 每次显示的字符数 |
| flags | int | 0 | 位标志：&1=同步等待, &2=换行, &4=前后半句切换 |

#### C# 实现

```csharp
/// <summary>
/// 打字机动画行。在渲染时按字符索引裁剪可见范围，不修改原始数据结构。
/// </summary>
sealed class TypingDisplayLine : ConsoleDisplayLine, IAnimatedDisplayLine
{
    private readonly long _startTimeMs;
    private readonly int _charDelayMs;
    private readonly int _chunkSize;
    private readonly int _totalVisibleChars; // 总可见字符数（不含 HTML 标签）
    private int _currentVisibleChars;
    private bool _isComplete;
    
    // 前后半句切换
    private readonly string[] _phases;      // [前半, 后半]
    private readonly int[] _phaseCharCounts; // 每个阶段的字符数
    private int _currentPhase;
    private int _phaseStartCharIndex;
    
    public bool IsAnimationComplete => _isComplete;
    public long AnimationStartTimeMs => _startTimeMs;
    
    public TypingDisplayLine(ConsoleButtonString[] buttons, int charDelayMs, 
        int chunkSize = 1, string[] phases = null)
        : base(buttons, isLogical: true, temporary: false, lineEnd: true)
    {
        _startTimeMs = Environment.TickCount64;
        _charDelayMs = Math.Max(charDelayMs, 1);
        _chunkSize = Math.Max(chunkSize, 1);
        _phases = phases;
        
        // 计算总可见字符数（遍历所有 ConsoleStyledString 节点）
        _totalVisibleChars = CountVisibleChars(buttons);
        _currentVisibleChars = 0;
        _isComplete = false;
    }
    
    public void UpdateAnimation(long elapsedMs)
    {
        if (_isComplete) return;
        
        int targetChars = (int)(elapsedMs / _charDelayMs) * _chunkSize;
        _currentVisibleChars = Math.Min(targetChars, _totalVisibleChars);
        
        if (_currentVisibleChars >= _totalVisibleChars)
        {
            _isComplete = true;
            _currentVisibleChars = _totalVisibleChars;
        }
    }
    
    public void ForceComplete()
    {
        _currentVisibleChars = _totalVisibleChars;
        _isComplete = true;
    }
    
    /// <summary>
    /// 渲染时裁剪：只渲染前 _currentVisibleChars 个字符
    /// </summary>
    public override void DrawTo(SKCanvas graph, int pointY, bool isBackLog, 
        bool force, TextDrawingMode mode)
    {
        if (_isComplete || _currentVisibleChars >= _totalVisibleChars)
        {
            // 动画完成，正常渲染
            base.DrawTo(graph, pointY, isBackLog, force, mode);
            return;
        }
        
        // 动画进行中：按字符计数裁剪渲染
        int remaining = _currentVisibleChars;
        foreach (ConsoleButtonString button in Buttons)
        {
            if (remaining <= 0) break;
            button.DrawToPartial(graph, new SKPoint(-1, pointY), 
                isBackLog, mode, ref remaining);
        }
    }
    
    /// <summary>
    /// 计算按钮数组中的总可见字符数
    /// </summary>
    private static int CountVisibleChars(ConsoleButtonString[] buttons)
    {
        int count = 0;
        foreach (var button in buttons)
        {
            if (button.StrArray == null) continue;
            foreach (AConsoleDisplayNode node in button.StrArray)
            {
                if (node is ConsoleStyledString css)
                    count += css.Text.Length;
            }
        }
        return count;
    }
}
```

#### ConsoleButtonString.DrawToPartial — 按字符计数裁剪渲染

```csharp
/// <summary>
/// 部分渲染：只渲染前 remaining 个字符，消耗 remaining
/// </summary>
internal void DrawToPartial(SKCanvas graph, SKPoint point, bool isBackLog, 
    TextDrawingMode mode, ref int remaining)
{
    float offsetX = 0;
    foreach (AConsoleDisplayNode node in StrArray)
    {
        if (remaining <= 0) break;
        
        if (node is ConsoleStyledString css)
        {
            if (css.Text.Length <= remaining)
            {
                // 整个节点都在可见范围内，正常渲染
                css.DrawTo(graph, point with { X = point.X + offsetX }, 
                    false, false, isBackLog, mode);
                offsetX += css.Width;
                remaining -= css.Text.Length;
            }
            else
            {
                // 节点部分可见：需要裁剪渲染
                // 方案：使用 DivideAt 克隆前半部分渲染，不修改原始数据
                var frontPart = css.DivideAt(remaining);
                if (frontPart != null)
                {
                    frontPart.SetWidth(StringMeasure, css.XsubPixel);
                    frontPart.DrawTo(graph, point with { X = point.X + offsetX }, 
                        false, false, isBackLog, mode);
                }
                remaining = 0;
                break;
            }
        }
        else
        {
            // 非文本节点（图片/形状）：始终渲染
            node.DrawTo(graph, point with { X = point.X + offsetX }, 
                false, false, isBackLog, mode);
            offsetX += node.Width;
        }
    }
}
```

**注意**：`DivideAt` 会修改原始节点。为避免副作用，需要在调用前克隆节点，或使用渲染裁剪法（SKCanvas clip rect）。

**替代方案：SKCanvas 裁剪法**

```csharp
// 计算前 remaining 个字符的像素宽度
int visibleWidth = CalculateVisibleWidth(css, remaining);
// 用 clip rect 裁剪渲染区域
graph.Save();
graph.ClipRect(SKRect.Create(point.X + offsetX, point.Y, visibleWidth, Config.LineHeight));
css.DrawTo(graph, point with { X = point.X + offsetX }, false, false, isBackLog, mode);
graph.Restore();
remaining = 0;
```

**决策**：SKCanvas clip rect 法更安全，不修改数据结构，且性能更好（GPU 级裁剪）。

### 3.3 FADE_PRINT 指令设计

> **v7.3.1 颜色格式注意**：`FADE_PRINT` 的 `startColor`/`endColor` 参数在 ERB 层使用 `0x00RRGGBB` 格式（`GETCOLOR()` 返回值），引擎内部转换为 `Color` 结构体时 alpha 默认 0xFF。如果未来需要支持 ARGB 透明度渐变，需注意 ERB 层 `0xAARRGGBB` 与引擎内部 `Color.FromArgb(int)` 的格式差异。详见 [color-pipeline.md](file:///d:/emuera/shared-trae/knowledge/erabasic/color-pipeline.md)

#### ERB 语法

```erb
; 文本颜色淡入（从背景色到当前色）
FADE_PRINT "你好世界", 8, GETBGCOLOR(), GETCOLOR()

; 文本颜色淡出（从当前色到背景色）
FADEOUT_PRINT "你好世界", 8

; 整行颜色渐变
FADE_PRINTL "你好世界", 8, 0x000000, 0xFFFFFF
```

#### 参数

| 参数 | 类型 | 默认值 | 语义 |
|------|------|--------|------|
| text | string | 必需 | 文本内容 |
| steps | int | 8 | 动画帧数 |
| startColor | int | GETBGCOLOR() | 起始颜色 |
| endColor | int | GETCOLOR() | 结束颜色 |
| duration | int | steps×100 | 总时长（ms） |

### 3.4 指令注册

```csharp
// Instraction.Child.cs 中新增
private sealed class TYPING_PRINT_Instruction : AInstruction
{
    public TYPING_PRINT_Instruction()
    {
        ArgBuilder = ArgumentParser.GetArgumentBuilder(FunctionArgType.STR_SP);
        flag = IS_PRINT;
    }
    
    public override void DoInstruction(ExpressionMediator exm, InstructionLine func, InstructionLine caller)
    {
        var arg = (SpStrArg)func.Argument;
        string text = arg.Str.GetStrValue(exm);
        long delay = arg.X.GetIntValue(exm);
        long chunkSize = arg.Y != null ? arg.Y.GetIntValue(exm) : 1;
        
        // 1. 解析文本为 ConsoleButtonString[]（复用现有 PrintStringBuffer 逻辑）
        var buttons = exm.Console.PrintStringBuffer.ParseAndCreateButtons(text);
        
        // 2. 创建动画行
        var animLine = new TypingDisplayLine(buttons, (int)delay, (int)chunkSize);
        
        // 3. 添加到 displayLineList
        exm.Console.AddAnimatedDisplayLine(animLine);
        
        // 4. 如果是同步模式（TYPING_PRINTW），等待动画完成
        if ((flag & 0x01) != 0)
        {
            exm.Console.WaitForAnimation(animLine);
        }
    }
}
```

### 3.5 渲染循环集成

```csharp
// EmueraConsole.OnPaint / MainWindow.OnPaint 中
// 在遍历 displayLineList 渲染时，检查动画状态

foreach (ConsoleDisplayLine line in displayLineList)
{
    if (line is IAnimatedDisplayLine animLine)
    {
        if (!animLine.IsAnimationComplete)
        {
            long elapsed = Environment.TickCount64 - animLine.AnimationStartTimeMs;
            animLine.UpdateAnimation(elapsed);
        }
    }
    line.DrawTo(canvas, pointY, isBackLog, force, mode);
    pointY += Config.LineHeight;
}

// 如果有未完成的动画行，请求下一帧重绘
if (displayLineList.Any(l => l is IAnimatedDisplayLine al && !al.IsAnimationComplete))
{
    Invalidate(); // 触发下一帧 OnPaint
}
```

### TYPING_PRINT vs KEYTYPING

| 维度 | KEYTYPING (ERB) | TYPING_PRINT (引擎) |
|------|-----------------|---------------------|
| 每帧操作 | CLEARLINE+SUBSTRING+PRINT+TWAIT | UpdateAnimation(计算字符索引) |

## 6. 风险与约束

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| DivideAt 修改原始节点 | 打字机裁剪时破坏数据 | 使用 SKCanvas clip rect 法，不修改数据 |
| 动画行与按钮交互 | 动画进行中按钮不可点击 | 动画完成后才激活按钮 |
| 多行动画同步 | 多行同时 fade 时需同步 | 共享 AnimationStartTimeMs |
| BackLog 兼容 | 动画行进入 BackLog 时应显示最终状态 | BackLog 渲染时 ForceComplete |
| PRINTN 行合并 | 动画行与 isLineEnd=false 行合并 | 动画行强制 IsLineEnd=true |
| 字符宽度计算 | CJK 字符宽度 ≠ 字符数 | 使用 StringMeasure 计算像素宽度 |

### 8.3 图片特效指令设计

#### LAYER_FADE — 图层淡入淡出

```erb
; 图层淡入：opacity 从 0 渐变到 255
LAYER_FADEIN "sprite_name", depth, x, y, durationMs

; 图层淡出：opacity 从 255 渐变到 0
LAYER_FADEOUT depth, durationMs

; 图层颜色渐变：ColorMatrix 从 A 渐变到 B
LAYER_FADECOLOR depth, startCM, endCM, durationMs
```

**引擎实现**：扩展 `ImageLayer` 为 `IAnimatedLayer`

```csharp
interface IAnimatedLayer
{
    bool IsAnimationComplete { get; }
    void UpdateAnimation(long elapsedMs);
    void ForceComplete();
}

sealed class FadeAnimatedLayer : ImageLayer, IAnimatedLayer
{
    private readonly long _startTimeMs;
    private readonly int _durationMs;
    private readonly int _startOpacity;
    private readonly int _endOpacity;
    private readonly float[]? _startCM;
    private readonly float[]? _endCM;
    private bool _isComplete;
    
    public bool IsAnimationComplete => _isComplete;
    
    public void UpdateAnimation(long elapsedMs)
    {
        if (_isComplete) return;
        float t = Math.Min((float)elapsedMs / _durationMs, 1.0f);
        // Easing: ease-out cubic
        t = 1 - MathF.Pow(1 - t, 3);
        
        Opacity = (int)(_startOpacity + (_endOpacity - _startOpacity) * t);
        if (_startCM != null && _endCM != null)
        {
            ColorMatrix = InterpolateColorMatrix(_startCM, _endCM, t);
        }
        
        if (t >= 1.0f)
        {
            _isComplete = true;
            Opacity = _endOpacity;
            ColorMatrix = _endCM;
        }
    }
    
    public void ForceComplete()
    {
        Opacity = _endOpacity;
        ColorMatrix = _endCM;
        _isComplete = true;
    }
}
```

**关键优势**：ImageLayer 已有 `Opacity` 和 `ColorMatrix` 属性，`BuildFilter` 已能根据这两个属性生成 SKColorFilter。动画只需逐帧更新这两个属性值，无需修改渲染管线。

```csharp
            durationMs: durationMs,

        exm.Console.SetAnimatedLayer(depth, animLayer);
```

```csharp
struct ScreenFlashState
{
    public int Color;
    public int Count;
    public long StartTimeMs;
    public long DurationMs;  // 单次闪烁时长
    public bool IsComplete;

// OnPaint 中
if (_flashState != null && !_flashState.Value.IsComplete)
{
    long elapsed = Environment.TickCount64 - _flashState.Value.StartTimeMs;
    long singleDuration = _flashState.Value.DurationMs;
    long totalDuration = singleDuration * _flashState.Value.Count * 2;
    
    if (elapsed >= totalDuration)
    {
        _flashState.Value.IsComplete = true;
    }
    else
    {
        // 计算当前是闪烁的亮半周期还是暗半周期
```

#### SCREEN_QUAKE — 屏幕震动

```erb
; 屏幕震动
SCREEN_QUAKE count, amplitude, durationMs
```

**引擎实现**：在渲染时偏移整个画布

```csharp
// MainWindow.cs
private ScreenQuakeState? _quakeState;

struct ScreenQuakeState
{
    public int Count;
    public int Amplitude;
    public long StartTimeMs;
    public long SingleDurationMs;  // 单次震动时长
    public bool IsComplete;
    private Random _rng;
    
    public (int dx, int dy) GetOffset(long elapsedMs)
    {
        if (IsComplete) return (0, 0);
        
        long singleDuration = SingleDurationMs;
        long totalDuration = singleDuration * Count;
        
        if (elapsedMs >= totalDuration)
        {
            IsComplete = true;
            return (0, 0);
        }
        
        // 在每次震动的中间偏移，两端回位
        long phase = elapsedMs % singleDuration;
        float t = (float)phase / singleDuration;
        // 正弦衰减：中间最大，两端为0
        float intensity = MathF.Sin(t * MathF.PI);
        int dx = (int)(_rng.Next(-Amplitude, Amplitude + 1) * intensity);
        int dy = (int)(_rng.Next(-Amplitude, Amplitude + 1) * intensity);
        return (dx, dy);
    }
}

// OnPaint 中
if (_quakeState != null && !_quakeState.Value.IsComplete)
{
    long elapsed = Environment.TickCount64 - _quakeState.Value.StartTimeMs;
    var (dx, dy) = _quakeState.Value.GetOffset(elapsed);
    canvas.Translate(dx, dy);  // 偏移整个画布
}
```

### 8.4 统一动画驱动架构

文本动画和图片特效共享同一套动画驱动机制：

```
┌─────────────────────────────────────────────────┐
│              OnPaint 渲染循环                      │
│                                                   │
│  1. 更新所有动画状态                               │
│     ├─ IAnimatedDisplayLine.UpdateAnimation()     │
│     ├─ IAnimatedLayer.UpdateAnimation()           │
│     ├─ ScreenFlashState.GetOffset()               │
│     ├─ ScreenQuakeState.GetOffset()               │
│     └─ BgColorFadeState.GetCurrentColor()         │
│                                                   │
│  2. 应用全局效果                                   │
│     ├─ canvas.Translate(quakeOffset)              │
│     └─ canvas.DrawColor(bgColor)                  │
│                                                   │
│  3. 统一 depth 循环（v7.0 起，三源合并降序）：      │
│     三个 depth 源：edepth(escapedParts) +          │
│       cbgList.zdepth + idepths(ImageLayer)         │
│     合并为统一降序列表 allDepths，每个 depth 按以下  │
│     顺序绘制：                                     │
│     ├─ ImageLayer（DrawLayersAtDepth）             │
│     ├─ CBG 图片 (CBGSETSPRITE/CBGSETG)            │
│     ├─ depth==0 时：displayLineList（文本行）       │
│     │   ├─ TypingDisplayLine: clip rect           │
│     │   └─ FadeDisplayLine: colorOverride         │
│     └─ escapedParts（div 属于此类，按 depth 排序）  │
│                                                   │
│  4. HTML_PRINT_ISLAND（最顶层）                    │
│                                                   │
│  5. 渲染闪烁覆盖                                  │
│     └─ canvas.DrawRect(flashColor)                │
│                                                   │
│  6. 如果有未完成动画 → Invalidate()               │
└─────────────────────────────────────────────────┘
```
